使用指南

如何配对？

两端打开 TransferBay。输入对方的六位数字，看到两台电脑显示相同的校验词后，在接收端允许连接。

找不到设备？

两端更新至 1.7 后，可用六位数字跨可互访的 192.168.x.x 网段连接。使用其他地址范围或找不到设备时，可展开「其他连接方式」，输入对方的备用长码。连接旧版时，可在「其他连接方式」里查看六位码，或输入对方 IP 和六位码。

地址也连不上时，检查系统是否允许 TransferBay 访问本地网络；访客 Wi-Fi 可能禁止同网设备互访。

不打开主窗口怎么发送？

先完成配对。Mac 拖着文件靠近菜单栏纸飞机时会出现投递窗口，松手即可发送，Windows 可将文件拖到桌面悬浮窗。悬浮窗可移动，也可用顶栏的「悬浮窗」按钮显示或隐藏。

文件保存在哪里？

发送端可拖入多个文件，单个最大 2 GB。桌面端在配对后自动保存收到的文件，文件进入本机下载文件夹中的「TransferBay 接收」，按发送方系统分目录。可在「传输记录」打开接收文件夹。浏览器访问时使用浏览器下载目录。文件显示「已接收」后即可断开。

网络设置

只填 IP 时使用此端口。对方端口不同时，输入 IP:端口。修改后退出并重新打开应用生效。

允许配对？

请核对另一台电脑显示的词。只有两边一致才允许连接。
